나만의 무기

<< 당구 게임 모드 >>

ImGui UI의 Cue Sports Mode 체크박스를 클릭하면 당구 게임 모드로 프로젝트를 실행할 수 있습니다.

이 모드에서는 중력이 사라지고, Firction 이 추가됩니다.

공을 피킹하면 공이 멈추고, 
마우스를 클릭 해제하면 선택한 공이 놓아집니다.
공을 놓을 때 마우스 이동 거리를 받아서 새로운 속도가 주어집니다.

공을 클릭할 때 클릭 라인 인디케이터가 화면에 출력됩니다.

라인 버텍스 버퍼와 상수 버퍼에 마우스 포지션을 업데이트 해서 
2d 좌표의 마우스 위치를 출력합니다.

버텍스 셰이더 프로그램을 1개 추가해서 라인을 그리는 버텍스 셰이더를 만들었습니다.
